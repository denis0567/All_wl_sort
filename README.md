# All_wl_sort

Список VPN-конфигов для обхода белых списков, который обновляется автоматически: нерабочие убираются, остальные отсортированы по скорости отклика. Подходит для Happ, v2rayNG и других клиентов с поддержкой подписок. Сейчас используются сборка конфигураций от solovyov-jenya2004/all_subs

## Ссылка на подписку

```
https://raw.githubusercontent.com/denis0567/All_wl_sort/main/sub.txt
```

## Как подключиться

### Happ
1. Скопируй ссылку выше.
2. Открой Happ и нажми «+» (добавить), выбери вставку из буфера обмена или сканирование QR-кода.
3. Подписка добавится, и в списке появятся серверы.

### Другие клиенты
Любое приложение, которое умеет добавлять подписку по ссылке или через QR-код: вставь ссылку или отсканируй код.

## Как это работает

- Файл `sub.txt` формирует и обновляет приложение, которое регулярно проверяет все конфиги. Сначала проверяется, отвечает ли сервер, затем что через него реально проходит трафик.
- В списке остаются только рабочие конфиги, самые быстрые по отклику идут выше.
- Три самых быстрых по скорости скачивания стоят в самом начале с пометкой **⭐ TOP** и скоростью в названии.
- Список меняется со временем: конфиги, которые перестали работать, пропадают, а ожившие возвращаются. Если выбранный сервер исчез, выбери другой из списка и обнови подписку.

## Важно

- Конфиги берутся из сторонних источников. Мы не управляем этими серверами и не отвечаем за их работу и безопасность.
- Не передавай через непроверенные серверы пароли и другие важные данные, если не уверен в источнике.
